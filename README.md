# MERN Image Upload App using ImageKit

## Features
- Upload image
- Add caption
- Store data in MongoDB
- Upload image to ImageKit
- Feed page with all uploaded posts
- React + Tailwind UI
- Deploy Ready
- Full MERN Stack

## Backend Setup

```bash
cd backend
npm install
npm run dev
```

## Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

## Deployment
- Frontend: Vercel
- Backend: Render
- Database: MongoDB Atlas
